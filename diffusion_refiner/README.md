# Shared diffusion model code

This directory contains the shared model definitions (`models.py`), scheduling/embedding utilities (`utils.py`), and the existing dependency list. The matched reference is trained and evaluated through `../paired_reproduction/run_component_ablations.py`, not a legacy evaluation CLI.

The current repository contains only the selected experiment drivers and their local source dependencies. Legacy training variants and demo utilities remain in earlier Git history and local archives. See the [repository README](../README.md) for the table-to-code map, required artifacts, and reproduction limits.
